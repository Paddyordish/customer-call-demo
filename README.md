# A Difficult Customer Call

An interactive Articulate Storyline portfolio demonstration by Patrick Ordish.

[Launch the course](https://paddyordish.github.io/customer-call-demo/)

The website opens the standalone Storyline player. It does not report scores or completion to an LMS. The original SCORM 1.2 launch file and manifest are retained for LMS use.

Published output is included here; the editable `.story` project is stored separately. An active Articulate subscription is required to edit the original project, but the exported website runs independently.
