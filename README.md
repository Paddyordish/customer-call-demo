# A Difficult Customer Call

An interactive Articulate Storyline portfolio demonstration by Patrick Ordish.

[Launch the course](https://paddyordish.github.io/customer-call-demo/)

The website opens the standalone Storyline player. It does not report scores or completion to an LMS. The original SCORM 1.2 launch file and manifest are retained for LMS use.

Published output is included here; the editable `.story` project is stored separately. An active Articulate subscription is required to edit the original project, but the exported website runs independently.

## Standard portfolio publishing workflow

Patrick's default for future portfolio courses is to upload published web output to GitHub and host the demo with GitHub Pages. Use the tested GitHub Pages URL in Upwork and other portfolio listings; use Articulate Review links for feedback where useful.

1. Retain the editable source project separately (for Storyline, the `.story` file).
2. Keep a SCORM ZIP for LMS delivery and export standalone web output for portfolio hosting. Where a SCORM export already includes a standalone player, verify it before reusing it.
3. Upload the published website and its assets to the intended GitHub repository, using public hosting only for content intended for the public portfolio.
4. Enable GitHub Pages and verify deployment, course launch, navigation, interactions and media before sharing.
5. Replace temporary Articulate links in portfolio listings with the verified GitHub Pages URL.
6. After revisions, republish and update the same repository to preserve the portfolio URL.
